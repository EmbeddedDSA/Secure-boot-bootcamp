How to use this bank

Every question asked in a grill, repetition check, oral exam or mock, with the score given and a model answer phrased the way a strong candidate would say it out loud. Practise by covering the model answer and answering aloud first.

Scale: 0 = blank, 1 = wrong direction, 2 = right idea but missing detail, 3 = would pass an interview.
